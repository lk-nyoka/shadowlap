# Lap data provenance

| File | Source | Licence | Committed? |

| `lap_a.csv` | Generated by `tools/make_synthetic_lap.py` (made-up track "Track A") | MIT, as the rest of this repo | yes |

Processing applied: interpolation to 100 Hz, 250 ms smoothing of speed,
"braking" = brake pedal on AND slowing by more than 2 m/s².
